# nlmixr2

nlmixr2 is an open-source ecosystem for nonlinear mixed-effects (NLME) modeling and pharmacometrics in R.
The nlmixr2 GitHub organization brings together the core nlmixr2 package and a collection of supporting packages for model estimation, simulation, visualization, diagnostics, and related pharmacometric workflows.

Key components include:

- **nlmixr2** – the main interface for NLME model development
- **rxode2** – simulation and solving of ODE-based models
- **nlmixr2est** – estimation routines
