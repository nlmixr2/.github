# nlmixr2

nlmixr2 is an open-source ecosystem for nonlinear mixed-effects (NLME) modeling and pharmacometrics in R.
The nlmixr2 GitHub organization brings together the core nlmixr2 package and a collection of supporting packages for model estimation, simulation, visualization, diagnostics, and related pharmacometric workflows.

Key components include:

- [**nlmixr2**](https://github.com/nlmixr2/nlmixr2) – the main interface for NLME model development
- [**rxode2**](https://github.com/nlmixr2/rxode2) – simulation and solving of ODE-based models
- [**nlmixr2est**](nlmixr2est) – estimation routines

If you want to use nlmixr2 with AI coding assistants take a look here:
- [**nlmixr2llm**](https://github.com/nlmixr2/nlmixr2llm) – a collection of skills for AI coding assistant to be used with nlmxir2

If you are coming from Monolix/NONMEM and want to convert your models then check:
- [**nonmem2rx**](https://github.com/nlmixr2/nonmem2rx) – is to convert a NONMEM control stream to a rxode2/nlmixr2
- [**monolix2rx**](https://github.com/nlmixr2/monolix2rx) – is to convert a Monolix model to a rxode2 simulation script
- [**babelmixr2**](https://github.com/nlmixr2/babelmixr2) – is to convert a nlmxir2/rxode2 model to a Monolix/NONMEM model
